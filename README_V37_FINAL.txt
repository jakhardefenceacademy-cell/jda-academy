Mobile install:
1. Deploy this package to the HTTPS custom domain.
2. Open the domain in Chrome on Android.
3. Use the Install App button or Chrome menu > Install app.

Security:
- Do not put Gmail passwords, API secrets, or private tokens in index.html.
- Use HTTPS and a secured backend endpoint for cloud sync.
- GitHub Pages is static hosting; server-side authorization must be enforced by the backend.
